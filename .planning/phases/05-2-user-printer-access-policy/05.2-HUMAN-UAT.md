| **Linux VM** (`admin-user@VM_HOST`) | `git pull`, `docker compose up -d --build` |

Após cada push do repositório, **sempre atualizar a VM** antes de testar UI/API em produção.

---

## Linux VM — atualizar stack (SSH)

```bash
ssh admin-user@VM_HOST
cd ~/printwatch
git pull origin master
docker compose up -d --build
```

O backend aplica o schema via `create_all` no startup (tabela `user_printer_access` é criada no restart).
Para migration Alembic manual: `cd backend && alembic upgrade head` no **Windows**, não dentro do container atual.

Verificar API: `curl -s http://localhost:8000/api/v1/health`
