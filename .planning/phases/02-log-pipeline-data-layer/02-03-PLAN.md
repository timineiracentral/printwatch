## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| page_log line → INSERT SQL | Conteúdo de campo do page_log entra no banco via ORM |
| observer.schedule path → inotify syscall | Path passado ao InotifyObserver vira syscall de kernel |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Tampering | repository.py INSERT | mitigate | SQLAlchemy ORM com parâmetros vinculados — nenhuma interpolação de string em SQL; prevent SQL injection via page_log content |
| T-02-07 | Denial of Service | watcher thread crash | mitigate | observer.daemon=True garante que morte do uvicorn mata o observer; /healthz expõe observer.is_alive(); restart: unless-stopped no compose reinicia o container |
| T-02-08 | Tampering | on_modified sem filtro de path | mitigate | Verificar event.src_path == PAGE_LOG_PATH antes de processar — evita processar eventos de outros arquivos em /var/log/cups/ |
| T-02-SC | Tampering | npm/pip installs | mitigate | Todos os pacotes verificados no Package Legitimacy Audit do RESEARCH.md |
</threat_model>
