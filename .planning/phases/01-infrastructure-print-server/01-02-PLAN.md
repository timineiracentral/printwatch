<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Rede REDACTED_IP/16 → CUPS :631 | Clientes IPP não confiáveis na LAN |
| Variável ALLOWED_NETWORK → cupsd.conf | Input de configuração via env |
| Container → impressoras LAN | Backend CUPS encaminha jobs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | page_log | mitigate | LogFilePerm 0644; volume não exposto à rede; sem world-writable |
| T-01-02 | Spoofing | CUPS IPP :631 | mitigate | ACL deny-by-default; Allow from REDACTED_IP/16 only (D-05, D-07) |
| T-01-03 | Elevation | Admin CUPS | mitigate | Senha forte em `.env`; usuário @SYSTEM; placeholders no repo (D-19) |
| T-01-04 | Tampering | ALLOWED_NETWORK env | mitigate | Validar CIDR no entrypoint; cupsd -t antes de subir |
| T-01-05 | Tampering | envsubst injection | mitigate | Whitelist: substituir APENAS `${ALLOWED_NETWORK}`; template versionado |
| T-01-SC | Tampering | apt packages | accept | Pacotes Ubuntu jammy oficiais; sem npm/pip nesta fase |
</threat_model>
