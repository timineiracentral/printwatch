    ```python
    from typing import Annotated
    from fastapi import APIRouter, Depends, HTTPException, Query
    from fastapi.responses import StreamingResponse
    from sqlalchemy.orm import Session

    from app.db.session import get_db_dep
    from app.schemas.jobs import JobFilters
    from app.services import csv_export

    router = APIRouter()

    @router.get(
        "/csv",
        responses={
            200: {
                "content": {"text/csv": {}},
                "description": "CSV agregado por job (UTF-8 BOM, separador ';')",
            },
            400: {"description": "Resultado excede 100k linhas — refine os filtros"},
        },
    )
    def export_csv_endpoint(
        filters: Annotated[JobFilters, Query()],
        db: Session = Depends(get_db_dep),
    ):
        total = csv_export.count_aggregated(db, filters)
        if total > csv_export.MAX_CSV_ROWS:
            raise HTTPException(
                status_code=400,
                detail=f"Resultado excede 100k linhas ({total}) — refine os filtros (date_from/date_to ou username)",
            )
        filename = csv_export.make_filename()
        return StreamingResponse(
            csv_export.iter_csv_rows(db, filters),
            media_type="text/csv; charset=utf-8",
            headers={"Content-Disposition": f'attachment; filename="{filename}"'},
        )
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| StreamingResponse → cliente HTTP | Stream pode durar segundos a minutos para CSV grande; conexão aberta + DB session retida (FastAPI ≥ 0.118 garante session aberta até stream terminar). |
| Cliente HTTP → CSV no disco | CSV gravado no cliente pode ser aberto em Excel; risco de CSV injection se valores começarem com `=`, `+`, `-`, `@`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05-01 | Tampering | CSV injection — valor começando com `=cmd|...` executa fórmula no Excel | mitigate-deferred | Prefixar valores `=`/`+`/`-`/`@` com `'` (single quote) ou ` ` (space). MVP: documentar como limitação aceita; Excel tem prompt "External data" por default. v2: ativar prefix. |
| T-03-05-02 | DoS | Cliente baixa CSV de 100k linhas várias vezes em paralelo | accept | MVP rede local; sem rate limiting (v2). |
| T-03-05-03 | Information Disclosure | CSV expõe `job_name` (nome de arquivo impresso) — pode conter dados sensíveis (ex: "Folha de pagamento.pdf") | accept | Mesma exposição do `/api/v1/jobs` que o dashboard já mostra. Decisão MVP (PROJECT.md sem auth). |
| T-03-05-04 | Resource Exhaustion | Session SQLAlchemy mantida durante stream longo | mitigate | yield_per=1000 batch processing; 100k cap. Sessions são NullPool — uma por request. |
| T-03-05-05 | Spoofing | filename no Content-Disposition pode ser manipulado se nome do printer/username contiver `\r\n` (header injection) | mitigate | filename usa apenas timestamp + literal — sem interpolação de entrada do cliente. |
</threat_model>
