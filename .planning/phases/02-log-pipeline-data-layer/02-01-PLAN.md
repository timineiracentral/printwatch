<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cups_logs volume → backend | Dados do CUPS (page_log) entram no backend via volume `:ro`; conteúdo é texto formatado mas pode conter entradas maliciosas |
| docker host → db_data volume | SQLite em volume Docker; não exposto por porta de rede |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | docker-compose.yml cups_logs mount | mitigate | Montar cups_logs como `:ro` no serviço backend — backend não pode corromper spool CUPS |
| T-02-02 | Information Disclosure | /app/data/printwatch.db | mitigate | DATA-03: entrypoint.sh aplica `chmod 600 $DB_PATH` antes de iniciar uvicorn; volume db_data não tem porta exposta |
| T-02-03 | Elevation of Privilege | Container backend rodando como root | accept | Container interno sem porta exposta na rede; acesso restrito ao volume `:ro`; risco baixo em rede interna MVP |
| T-02-SC | Tampering | pip install em requirements.txt | mitigate | Package Legitimacy Audit em 02-RESEARCH.md verifica todos os pacotes — todos aprovados sem flags |
</threat_model>
