# Milestone v1.0: Audit Platform

**Status:** ✅ SHIPPED 2026-05-27  
**Phases:** 1–4  
**Total Plans:** 23 (5 + 5 + 6 + 7)

## Overview

Primeira entrega utilizável do PrintWatch: print server CUPS intermediário, captura automática de jobs no SQLite, API REST com filtros/exportação e dashboard web para auditoria de impressão na rede local.

**Promessa entregue:** Todo job impresso via PrintWatch fica registrado, consultável e exportável — com impressão física independente de falhas no backend/dashboard.

## Milestone Summary

**Key Decisions:**
- CUPS como print server intermediário (descartado Windows Server / DHCP VM)
- SQLite + Docker Compose; ingestão 1 linha/página; agregação na API por job
- Username persiste AS-IS do CUPS (sem prefixo AD artificial); LDAP = milestone futura
- `/printers` via DISTINCT no log (sem runtime CUPS) — cadastro formal adiado para v1.5

**Issues Resolved:**
- GAP-02-01: aspas no nome da impressora no parser
- GAP-02-02: username sem domínio AD via IPP Windows (investigação fechada)
- Deploy VM operacional com jobs reais validados

**Deferred to later milestones:**
- SERVER-04, DEPLOY-03, DEPLOY-04 — estavam na antiga Fase 5; realocados (v1.5 / v3.0)
- Cadastro de impressoras, departamentos, custos, toner — v1.5 Management Platform

- `LOG_RETENTION_DAYS` default 90 no código vs “1 ano” no PRD — configurável via env
- Excel EXPORT-02 validado estruturalmente na VM; abertura GUI Windows recomendada
